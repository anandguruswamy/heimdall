Offset-Free Joint Time-of-Flight, Clock-Rate, and Clock-Drift Estimation from Networked UWB Timestamps

Heimdall Project Technical Paper

Multi-Node Ultra-Wideband Sensing System, July 2026

Abstract--This paper develops a timestamp-domain method for jointly estimating reciprocal radio time of flight (ToF), relative clock frequency, and clock-frequency drift in an unsynchronized ultra-wideband (UWB) network. The central observation is that absolute clock offsets are unnecessary nuisance parameters when transmit and receive events are combined into two-way local intervals. An affine-clock two-way exchange yields an equation of the form qiRi - qjDj = 2τij, where q is seconds per local tick and τ is reciprocal propagation time. Clock offsets cancel exactly. Stacking such equations across repeated exchanges and a connected network produces a sparse, robust estimation problem for all link ToFs and node clock rates; time-varying rate terms extend the same construction to drift. Measurements from a five-node DWM3001/DW3110 deployment support the model: 16,909 observations over 30 s covered all 20 directed links, with a maximum measured relative drift of 0.00013194 ppb/ms and reverse-link consistency of 0.00000086 ppb/ms RMS. The measured drift is negligible over a 70 ms ranging exchange but becomes relevant to long-horizon timestamp prediction. Practical fitting horizons and identifiability conditions are given.

Index Terms--Ultra-wideband, time of flight, two-way ranging, clock skew, clock drift, synchronization, distributed estimation, timestamp fusion.

I. Introduction

UWB radios expose precise hardware timestamps, but timestamps generated by different radios do not share an origin or an exact rate. A conventional synchronization pipeline first estimates clock offset and skew, maps every timestamp into a selected clock domain, and only then estimates propagation delay. That decomposition is intuitive but introduces a state that ranging does not require: absolute inter-node clock offset.

Two-way ranging avoids this dependency. Transmit and receive timestamps are differenced within the clock that generated them, and suitable combinations of the resulting local intervals cancel clock offsets. Standard single-sided and double-sided two-way ranging (SS-TWR and DS-TWR) use this principle for one pair and one exchange [2], [3]. The same principle can be lifted from an isolated ranging transaction into a network estimator. Rather than compute each range independently with a fixed nominal tick period, the estimator can fit reciprocal ToFs, per-node tick periods, and their slow variation jointly from many timestamp equations.

This view is useful for scheduled sensing networks. Every transmitted beacon can serve simultaneously as data transport, a ranging event, and clock-rate evidence. No node needs to be a timing authority. No explicit clock-offset state is required for ranging. The host uses event identities and local intervals, while a single scale convention supplies SI units.

The contributions of this paper are:

  1. an offset-free system model for networked transmit and receive timestamps;
  2. a joint linear formulation for reciprocal ToF and affine clock-rate estimation;
  3. a locally linear extension for clock drift and long-running state estimation;
  4. identifiability and practical implementation conditions; and
  5. an empirical characterization from a five-node UWB deployment.

II. System Model

A. Network and Propagation

Consider N UWB nodes indexed by i in a connected observation graph. Event e is a transmission by node i at true time te. Node j receives the event after propagation time τij,e. For fixed nodes and reciprocal propagation,

τij,e = τji,e = τij.(1)

The geometric range is dij = cτij, where c is the propagation speed. Antenna delays, leading-edge bias, and NLOS delay are additive hardware/channel terms unless separately calibrated.

B. Local Clock Model

Each radio reports a local hardware-clock value. Over a short interval, node i's clock is modeled as

Ci(t) = φi + ωi(t - t0) + (1/2)γi(t - t0)2.(2)

Here φi is an arbitrary offset, ωi is ticks per second, and γi is rate change. Define the inverse rate qi = 1/ωi, measured in seconds per tick. Around time coordinate u, use

qi(u) = qi,0 + qi,1u.(3)

This inverse-rate parameterization makes the interval equations linear. Relative frequency in ppm is recovered as 106(q0/qi - 1), after one node or the nominal device rate defines the scale.

C. Timestamp Observations

A frame transmitted by i carries a local transmit timestamp si,e = Ci(te). Receiver j records rj,e = Cj(te + τij,e) plus timestamp noise and channel bias. A single directed observation therefore contains clock offset and ToF in the same additive term; neither is identifiable from that observation alone.

In the target implementation, the DW3110 timestamp counter is 40 bits at 63.8976 GHz, approximately 15.65 ps per device time unit (DTU). The counter wraps every 17.2 s. Event labels and schedule rounds support unwrapping over longer captures, while any individual modular interval must remain below the half-range ambiguity bound.

III. Problem Statement

Given timestamped directed receptions over an observation horizon, estimate:

  1. the reciprocal link ToFs τij or a slowly varying ToF trajectory;
  2. the relative inverse clock rates qi,0, equivalently clock ppm;
  3. the local rate derivatives qi,1, equivalently clock drift; and
  4. uncertainty and residual diagnostics robust to missing frames and outliers.

The estimator should not solve for φi, because clock origins are neither needed for reciprocal ToF nor observable without a gauge. It should accept asynchronous forwarding and packet loss, use timestamps in the clock domain that produced them, and exploit all links rather than treating every pair independently.

Formally, construct local-interval measurements z and find parameters x containing link ToFs and node rate terms such that

x* = arg minx Σm ρ((Amx - bm)/σm),(4)

where ρ is a robust loss and the clock-offset columns are absent by construction. A reference-rate constraint fixes physical scale. Absolute UTC synchronization is explicitly outside the problem.

IV. Proposed Offset-Free Solution

A. Two-Message Interval Equation

Let A transmit a poll at local timestamp a1, received by B at b1. B later transmits at b2, received by A at a2. Define the local round and reply intervals

RA = a2 - a1,   DB = b2 - b1.(5)

Under constant rates during the exchange, both represent the same true turnaround interval, except that the round interval contains propagation in both directions. Consequently,

qARA - qBDB = 2τAB + ν1.(6)

The offset terms φA and φB cancel inside (5), before estimation. Equation (6) is linear in inverse rates and ToF. If rates are known, it reduces to corrected SS-TWR. If rates are unknown, repeated and network-coupled instances estimate them jointly with ToF.

B. Three-Message DS-Like Equation

Add a final transmission by A at a3, received by B at b3. The complementary intervals are

RB = b3 - b2,   DA = a3 - a2,(7)

which give a second offset-free constraint:

qBRB - qADA = 2τAB + ν2.(8)

Equations (6) and (8) retain the DS-TWR cancellation mechanism but do not force a closed-form range calculation per triple. They become rows in one network optimization. This permits shared rate estimates, weighting by timestamp quality, missing-equation tolerance, and direct uncertainty propagation. The familiar asymmetric DS-TWR expression

τ̂ = (RARB - DADB) / (RA + RB + DA + DB)(9)

is recovered as a pairwise special case under the standard short-exchange clock assumptions [3]. The proposed method instead preserves qi as a network state and allows that state to evolve.

C. Joint Network System

For an A-to-B-to-A exchange, a design row contains nonzero coefficients only for qA, qB, and τAB:

[... RA ... -DB ... -2 ...]x = 0.(10)

Fixing q0 to the nominal DTU period moves its contribution to the right-hand side and removes the all-zero scale ambiguity. Every node rate is shared by all incident links, while each reciprocal link contributes one ToF state. The sparse matrix can be solved by weighted least squares, iteratively reweighted least squares, or a factor-graph optimizer.

D. Drift Extension

For an interval centered near schedule coordinate u, replace qi by qi,0 + qi,1u. Equation (6) becomes

(qA,0 + qA,1u)RA - (qB,0 + qB,1u)DB - 2τAB = ν.(11)

This remains linear when u is supplied by a round counter or a previous timing iterate. For long deployments, a state-space implementation should model qi as a random walk or integrated random walk rather than assuming one global quadratic clock. Offsets still do not enter.

Interpretation: the method estimates enough clock behavior to compare durations, not clock origins. This is sufficient for reciprocal ToF. It does not produce absolute transmit time, UTC, or passive one-way ToF from a single reception.

V. Identifiability and Observability

Offset elimination does not remove all gauge freedoms. The following conditions are required:

  1. Rate scale: fix one inverse rate to a nominal or calibrated value. Without this constraint, rates and ToFs can scale together.
  2. Connected graph: every estimated node must participate in a path to the rate reference.
  3. Reciprocal evidence: a link needs alternating directions or an equivalent cycle of timestamp constraints. A lone directed timestamp cannot separate offset and ToF.
  4. Timing diversity: repeated equations must have sufficient variation or complementary DS geometry. Identical turnaround intervals can make rate and ToF columns poorly conditioned.
  5. Drift excitation: the observation window must be long enough that rate change exceeds local skew noise, but short enough for the selected drift model to remain valid.

Reciprocity is a physical constraint, not merely a convenience. Direction-dependent antenna or NLOS biases violate (1) and should be represented by calibrated directional terms or robust residuals. Motion creates a second confounder: a changing path delay can resemble clock-rate error. Multiple links, geometry constraints, CIR diagnostics, and sufficiently rapid alternating exchanges help separate these effects.

Fixing the reference tick period to its data-sheet value yields ToF in SI seconds, but any common reference-frequency error scales all ranges. A calibrated frequency reference is required when that ppm-level scale error matters.

VI. Estimation Procedure

Algorithm 1: Offset-Free Joint Estimator
  1. Validate records, deduplicate relayed observations, and unwrap each 40-bit clock using event order.
  2. For each unordered pair, identify alternating two- or three-message exchanges from node, round, and schedule labels.
  3. Form only within-clock modular intervals R and D; reject intervals at or above half the timestamp modulus.
  4. Build sparse rows from (6), (8), or (11), sharing node-rate states across links and one reciprocal ToF state per pair.
  5. Fix the reference inverse rate, apply antenna-delay calibration, and solve with robust, quality-weighted least squares.
  6. Reject or down-weight high-residual/NLOS factors, then re-solve and compute covariance or bootstrap intervals.
  7. For continuous operation, marginalize old factors while carrying rate and drift states forward.

Quality weights can include accumulator count, first-path validity, received power, CIR/NLOS indicators, timestamp route, and exchange span. Packet loss removes rows but does not invalidate intact exchanges. A global solver also exposes consistency tests unavailable to isolated DS-TWR: reverse-direction residuals, cycle closure, per-node drift decomposition, and graph rank.

A practical implementation may alternate two subproblems. First hold link ToFs fixed and update clock rate/drift states from all directed links. Then hold clock states fixed and update ToFs or geometry. Since (10) is already linear for static ToFs and local drift, this alternation is primarily useful when adding motion, robust NLOS models, or geometric position constraints.

VII. Heimdall Timestamp Realization

Heimdall uses DWM3001CDK nodes with DW3110 radios and nRF52833 MCUs. Nodes broadcast scheduled beacons; each frame carries its programmed delayed-transmit timestamp. On validated hardware, programmed-versus-actual transmit error was 0 DTU over 1,000 test frames. Each receiver records its local RX timestamp and reports the observed TX timestamp verbatim. Thus every canonical observation contains a timestamp from the transmitter's clock and one from the receiver's clock.

The current configuration uses 7 ms superslots. Each receiver observes every other transmitter, producing a complete directed link matrix when frames are received. The host identifies A-to-B-to-A triples spanning no more than two network cycles and 100 ms, then computes conventional asymmetric DS-TWR. The proposed estimator can consume the same canonical records while replacing independent pairwise formulas with the sparse network system above.

Transmit timestamps include configured TX antenna delay; RX timestamps use the radio's receive timestamp primitive. Therefore raw timestamp solutions still require antenna-delay calibration and NLOS treatment. Clock cancellation cannot remove deterministic radio-front-end bias.

VIII. Practical Clock Measurements

A. Data Set and Method

A protected static capture retained 30 s of post-trigger traffic from five nodes. It contained 16,909 unique canonical observations over rounds 445320 through 449606, covering all 20 directed links. Parser CRC and framing failures were zero. Twelve USB sequence gaps occurred but did not prevent per-link fitting.

For each directed link, TX and RX counters were unwrapped independently. Robust one-second affine fits, advanced every 250 ms, estimated local relative skew. A robust trend through these local estimates produced drift. A full quadratic timestamp fit supplied an independent comparison. Finally, all directed drifts were decomposed into per-node values relative to N0.

B. Interpretation

Opposite directions exhibit nearly equal and opposite drift, and a node-level model explains the link slopes with a residual two orders of magnitude below the slopes themselves. This supports a clock-origin interpretation rather than a parser or propagation artifact. It also supports sharing a node clock state across all incident links, as required by (10).

The experiment validates relative drift only over 30 s and under the observed thermal conditions. Overlapping one-second windows make regression confidence intervals optimistic for long-term prediction. A longer holdover experiment is required before one quadratic clock model is extrapolated over minutes.

IX. Feasible Estimation Horizons

A. ToF Exchange Horizon

If rate drift d is left unmodeled after correcting constant skew, clock curvature grows approximately as (1/2)dT2. At the maximum measured relative drift of 0.132 ppb/s, the one-way light-distance scale is:

These are conservative scale values before DS-like cancellation, not predicted range errors. The practical recommendation is to keep each exchange at or below the existing 70 ms span. Independent short-exchange ToFs may be averaged for seconds or minutes if geometry remains static; the clock model does not require one long ranging transaction.

B. Clock-Rate Horizon

One-second local fits exhibited approximately 0.4-1 ppb residual noise. A 1-10 s window is therefore suitable for an instantaneous ppm estimate. At the maximum observed drift, true relative frequency changes by 0.132 ppb/s: 1 ppb in 7.6 s, 5 ppb in 38 s, and 10 ppb in 76 s. A single constant-ppm estimate should not represent a long record when ppb precision is required. Sliding estimates can operate indefinitely.

C. Drift Horizon

Clock drift requires enough time for skew change to exceed local skew noise. About 10 s is the shortest useful window for the fastest measured pair; 30 s produced coherent estimates across the full graph. A 30-60 s sliding window is a reasonable initial operational choice. The longest experimentally justified single-slope horizon is presently 30 s. Longer campaigns should use repeated local drift states rather than one global polynomial.

X. Discussion and Limitations

Offset-free is not synchronization-free. The estimator avoids explicit offset states because reciprocal ToF depends on durations. Scheduling still needs coarse phase coordination, and passive one-way localization still needs clock-offset information or additional geometric constraints.

Hardware bias remains. Antenna delays and timestamp leading-edge bias are indistinguishable from propagation delay in the basic model. Pairwise calibration, known geometry, or additional bias states are required for accurate metric ranging.

Motion and clock drift can couple. A moving endpoint changes ToF. Over a single link, that trend can resemble rate error. A complete multi-node graph, reciprocal directions, short exchange spans, and independent CIR motion indicators improve separation.

Global polynomials are fragile. Crystal behavior responds to temperature, voltage, and aging. A quadratic clock fit may describe 30 s while failing as a minute-scale predictor. The appropriate long-horizon object is a sequence of local rate/drift states with process noise.

Rank must be monitored. A fixed deterministic schedule can repeat nearly identical intervals. The solver should report condition number and state covariance. Deliberate low-amplitude turnaround diversity may improve clock-rate observability without changing average traffic load.

Common mode is unobservable. Network timestamps determine relative rate and drift. Absolute SI accuracy inherits the selected reference oscillator unless calibrated against PPS, GNSS, a disciplined oscillator, or another external standard.

XI. Validation Plan

The next experiment should test prediction, not merely in-sample fit:

  1. retain 10-30 min of complete raw timestamp traffic under static geometry;
  2. fit rate and drift on an initial 30-60 s segment;
  3. predict held-out timestamps over increasing horizons;
  4. compare constant-rate, quadratic, sliding-window, and state-space models;
  5. repeat with controlled thermal perturbation;
  6. measure ToF against surveyed pair distances after antenna-delay calibration; and
  7. compare the joint estimator against pairwise asymmetric DS-TWR using identical evidence.

Primary outputs should include held-out timestamp error versus horizon, ToF bias and variance, graph condition number, node-rate covariance, reverse-link closure, and robustness under synthetic record loss. This determines a defensible update cadence for each state.

XII. Conclusion

Reciprocal UWB ToF does not require explicit estimation of clock offsets. By forming local intervals from alternating transmit and receive events, offsets cancel before optimization. The resulting equations are linear in inverse clock rate and ToF, and they naturally extend to a sparse network system that jointly estimates link delays, node ppm, and local clock drift.

Heimdall measurements indicate that static ppm differences are large enough to require rate correction, while short-term drift is small enough to be negligible within the current 70 ms DS-like exchange. Over longer horizons, the same drift accumulates quadratically and should be tracked using 30-60 s local states. The architecture therefore separates timescales: short reciprocal exchanges for ToF, short sliding windows for ppm, and longer local windows for drift, all without carrying absolute clock-offset states in the ranging estimator.
